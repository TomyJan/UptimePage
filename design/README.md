# 首页设计探索

当前阶段用独立 HTML 原型比较视觉方向，不接入真实监控，也不代表生产技术结构已实现。页面数据、历史、事件和证书均为模拟数据。

当前预览：[A 精进原型](prototypes/refined-a.html)。[最初三方向](prototypes/homepage-directions.html) 保留用于对照。均可直接用浏览器打开，不需要安装依赖。

## A 精进

根据用户反馈，保留 A 的页面顺序和两级分组，集中调整以下内容：

- 文案：只留标题、状态、分组、数据和必要操作，删除宣传句、说明段落及逐行重复标签。
- 层级：中性色背景与卡片、少量鸢尾品牌强调色，已移除配色比较器。正常历史条独立使用固定绿色 `#4b9d71`，不跟随品牌色或深浅色更换；故障、提醒、维护的语义颜色独立，无数据使用空心条。
- 表面：卡片 16 px 圆角、轻阴影、故障边标；分组与菜单使用更小一档圆角，避免所有区域看起来相同。
- 动效：导航栏与分组控件保持稳定，子分组滑块约 360 ms、列表切换约 440 ms、首页与详情过渡约 520 ms。图表在切换完成后用 1450 ms 绘制，刷新与主题切换不重播曲线。列表重排与卡片悬停分别处理，避免互相覆盖；支持系统“减少动态效果”，不支持页面过渡 API 时使用淡入退化方案。
- 菜单：语言、时区、外观、刷新频率和样例数量均为自定义菜单，无原生 `select`；支持方向键、Esc、焦点恢复和点击外部关闭。旧菜单独立退出，新菜单从自己的按钮进入，避免快速切换时位置、尺寸与动画冲突。
- 提示：历史条块与可用率使用自定义提示，无 `title` 提示。悬停立即显示、连续滑动同步换内容，透明度与位移动画分别为 100 / 160 ms；手机点按、键盘左右键同样可查。
- 图表与页脚：曲线使用保留原始采样点的单调三次插值，平滑连接且不制造额外峰谷；绘制改用裁切揭示，修正缩放后虚线描边导致的右端缺口。纵轴与曲线使用相同的坐标映射，宽度变化时重算横向坐标，保留刻度文字大小。页脚只保留站点名。
- 信息去重：删除列表上方的“服务 + 数量”、详情底部的“更新于”、历史面板重复的可用率；指标周期合并进指标标题，最新响应下不再重复“最后检查”。详情仅在服务信息中显示一次检查时间。
- 操作：删除列表上方独占一行的操作区。“异常优先”紧接状态摘要文字，使用可切换的轻量按钮；刷新与“更新于”合成分段按钮，点时间立即刷新，点箭头选择周期。
- 刷新：访客可选跟随站点、仅手动、每 30 秒、每分钟或每 5 分钟，并保存本地偏好。站点默认由原型的 `prototypeConfig.refreshIntervalSeconds` 配置，当前为 60 秒，`0` 关闭自动刷新；这只是原型默认，不代表正式项目的请求预算已确定。自动模式显示倒计时，手动刷新完成后重置周期；隐藏页面暂停自动请求，恢复时过期只补一次。自动刷新不发通知、不重播图表动画。
- 通知：外层为透明、穿透点击的全屏浮层，无背景面板、固定消息区宽高或滚动容器；单张卡片独立定位并适配屏宽。最多同时显示 5 条，短屏按实际高度减少。新消息从底部进入，把旧消息向上推；放不下的旧消息退出并销毁，不排队，也不在关闭新消息后补回。支持关闭按钮、深浅色、中英文和出入重排动画，悬停、键盘焦点或页面隐藏时暂停倒计时。顶部“试用提示”供原型验收，不属于正式页面。
- 滚动：导航固定在视口顶部，向下滚动逐步收起，向上滚动逐步展开；停止后平滑收束，返回顶部完整显示。导航保留原有空间，收起不使正文跳动。原型工具栏在导航下方，不属于正式页面。
- 回顶：上翻且尚未到顶部时，右下角出现圆形箭头按钮；停止滚动后保留，下翻或到顶时淡出。点击平滑回顶，系统减少动态效果时直接回顶。按钮层级高于通知，出现时通知平滑上移让出空间。

除原有参考外，读取了 [Supabase / OpenDesign](https://opendesign.cc/packs/supabase/spec.json) 的 8 / 16 px 圆角、轻阴影和 150 / 200 ms 反馈规范，以及 [Raycast / OpenDesign](https://opendesign.cc/packs/raycast/spec.json) 的悬停阴影与透明度反馈。实看 Kuma Mieru 的卡片、Tab 和摘要表面后，将其较柔和的风格适配到 A 的行卡布局。新配色为本项目自行设计，已加深小字号状态文字以保证可读性；没有移植品牌素材。

本次验证：浅深色、中文英文、分组 / 搜索 / 空态 / 置顶、自定义菜单选择与键盘操作、提示同步显示 / 连续切换 / 退出、手机点按和减少动态效果；50 条列表在 320、390、768、801、1024、1440 px 下无全页或行卡横向溢出，菜单和提示均未越过左右屏幕边界。

动效复核覆盖快速连续切换大分组、子分组、三个导航菜单与图表范围，以及首页和详情往返；确认最终选择一致、旧弹层清理完成。另验证主题切换保留图表节点、减少动态效果与无页面过渡 API 的路径；对平滑曲线逐段检查，未超过相邻采样点的范围。

## 配色专项（2026-10-21）

上一版的问题是背景、卡片、控件、曲线和大面积正常历史同时偏绿。此次把表面颜色、品牌颜色和状态颜色分开：表面负责层次，强调色只用于品牌与选中操作，状态色集中在徽标与异常记录。三个方案沿用同一布局与状态语义，方便直接比较。

| 方案 | OpenDesign 参考 | 本项目采用与调整 |
| --- | --- | --- |
| 墨黑 | [Vercel](https://opendesign.cc/packs/vercel/spec.json)：白底、`#171717` 正文、`#fafafa` 次级表面 | 使用 `#171717` 强调，浅色主底 `#f7f7f8`；深色保持中性炭黑 |
| 鸢尾（已选定） | [Mercury](https://opendesign.cc/packs/mercury/spec.json)：`#5266EB` 强调，深色表面配单一明亮强调色 | 品牌与曲线采用 `#5266eb`，小字交互加深到 `#4558d4`；不将蓝色混入整页背景 |
| 暖橙 | [PostHog](https://opendesign.cc/packs/posthog/spec.json)：暖土色表面、`#F44E00` 强调 | 降低原方案的土色覆盖，主底 `#faf8f4`；强调加深为 `#b43d08`，深色使用杏橙色 |

参考的是配色组织与明确的原始参数；补充的浅色、深色、可读性调整与监控状态色是本项目的适配设计，不冒称参考站点的完整原配色。上表保留配色探索记录；用户已选定鸢尾，当前原型不再提供三套配色切换。

专项验证覆盖三套配色的深浅色、三个图表范围、右端完整显示、缩放后坐标重算、信息去重；通知覆盖多条并存、单条关闭、独立超时、悬停暂停、深浅色切换、中英文与过量提示收束。320–1440 px 下未出现页面或通知横向溢出，浏览器未捕获脚本错误。

后续验证覆盖固定绿色历史条、摘要中的异常优先、手动刷新、两轮自动刷新、手动重置周期、站点关闭自动刷新及自定义周期。最新通知验证改为：连续 12 条只保留最新可容纳的消息，关闭后旧消息不再出现，缩小窗口同样优先保留新消息。中英文在 320–1440 px、横屏 568 × 320 下无页面横向溢出，通知外层透明、无滚动区域，可见卡片在视口内。另用真实时间复核浅深色、刷新菜单、通知动画与反复调整窗口尺寸；滚动验证覆盖导航隐藏和展开、回顶按钮停止后保留、下翻与到顶隐藏、通知让位及减少动态效果，未捕获脚本错误。

## 三种方向

| 方向 | 主要区别 | 取舍 |
| --- | --- | --- |
| A：清晰留白（推荐） | 中性色、清楚的状态摘要、独立行卡；首页展示状态、历史、可用率、最新响应 | 更适合公开访问；单屏条目数适中 |
| B：紧凑控制台 | 深色默认预览、紧密网格、更矮的行卡、响应趋势小图 | 单屏能看到更多服务；技术感更强 |
| C：暖色目录 | 暖白、直角、非对称布局；桌面左侧说明、右侧列表 | 更有个性；桌面响应时间移入详情，列表留白更多 |

方向 B 默认用深色便于比较；正式站仍遵守基础设计中的“跟随系统主题”。所有方向均可在导航菜单手动切换深浅色。

## 可操作范围

- 切换大分组、子分组与“全部”；大分组切换后回到“全部”。
- 搜索名称、开启异常优先、切换 10 / 50 条模拟条目。
- 点击更新时间手动刷新，或从箭头菜单选择自动刷新频率、恢复站点默认。
- 下翻收起导航、上翻展开；上翻时可用右下角圆形按钮回到顶部。
- 点开服务详情，返回列表，切换响应曲线的时间范围。
- 导航栏分别弹出语言、时区、主题菜单；偏好保存在本地浏览器，选“跟随”可恢复自动。
- 中文、英文、正常、故障、维护、暂停、更新延迟及数据缺失示例。
- 键盘焦点、Tab 方向键操作、跳过导航链接、手机布局。

顶部深色比较栏属于设计工具，不属于正式网站。所有数据与刷新均为模拟；历史条块用于比较视觉，不能用来推导样例百分比。详情的三个时间范围也是演示，最终以来源实际提供的数据为准。

## 参考与采用范围

实看以下页面后，采用其信息组织思路，未复制品牌素材：

- [Kuma Mieru](https://kuma-mieru.vercel.app/) / [项目](https://github.com/alice39s/kuma-mieru)：丰富的延迟、历史和状态展示；将详细信息下放到详情，保留瘦长行卡。
- [OpenAI Status](https://status.openai.com/)：当前状态优先、历史条块易扫读。
- [GitHub Status](https://www.githubstatus.com/)：逐服务历史与可用率；不采用其大幅插画。
- [Vercel Status](https://www.vercel-status.com/)：克制的颜色、分隔与空间。
- [Cloudflare Status](https://www.cloudflarestatus.com/)：异常、维护与近期事件分开表达；正式项目是否支持对应事件字段要看上游能力。

使用 [OpenDesign 协议](https://opendesign.cc/skill.md) 进行参考选择、参数拆解和自审。其自动推荐没有匹配中文、可用率等专用需求，故从实际目录人工筛选以下系统，状态页的业务结构以上述页面为依据：

| 参考规范 | 采用的参数与规则 | 本项目的调整 |
| --- | --- | --- |
| [Vercel](https://opendesign.cc/packs/vercel/spec.json) | `#ffffff` / `#fafafa` 背景、`#171717` 正文、`#666666` 次要文字、`#ebebeb` 边线、4 px 间距基准、6 px 圆角 | 首页标题缩到 40 px，适应中文；加入语义状态色 |
| [Linear](https://opendesign.cc/packs/linear/spec.json) | `#08090A` 背景、`#F7F8F8` 正文、半透明边线、4 px 节奏、紧密面板、150 ms 反馈 | 提高次要文字对比度；不用营销页面的 64 px 标题 |
| [Aesop](https://opendesign.cc/packs/aesop/spec.json) | `#FFFEF2` 背景、`#333333` 正文、`#666666` 次要文字、直角、非对称网格、200 ms 反馈 | 左侧说明替代商品图片；手机改为单栏；状态语义色单独定义 |

规范仅提供字体分类，原型使用系统中文 / 英文字体，并未冒称加载品牌字体。深浅色的补充参数、状态颜色及图表均是本项目的适配设计。

## 自审与下一步

按 OpenDesign 的参考一致性、视觉层级、细节、功能、辨识度五项自审：保留三种不同的信息密度与布局，删除无用途的营销装饰；发现并修正手机图表刻度过小、英文摘要换行和外部分组历史误用故障样例的问题。独立审阅还发现并修正跨组后退的子分组残留、事件样例串组、图表及事件未应用时区的问题。

本地浏览器验证覆盖分组、搜索、空态、异常优先、50 条唯一详情地址、详情时间范围、键盘 Tab 切换、主题保存和时区切换；三方向在 320、390、768、801、900、1024、1440 px 宽度下，50 条列表均未出现全页或行卡横向溢出。此验证针对设计原型，不替代正式实现的测试。

目前推进的是 A 的交互细化，配色已确定采用鸢尾。卡片字段、历史粒度、详情组成、可置顶状态、各来源能力差异和完整加载 / 错误状态仍需确认，不能据本原型视为需求已定稿。
