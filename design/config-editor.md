# 配置编辑器原型

浮动方案已于 2026-10-22 确认，作为正式开发的交互基准。[原型](prototypes/config-editor-floating.html) 可直接打开；[原独立页方案](prototypes/config-editor-standalone.html) 保留供对比。

## 正式实现约束

- 使用现有前端的配色变量、组件和样式；原型颜色仅作演示，不替换现有规范。
- 构建环境变量 `UPTIMEPAGE_CONFIG_EDITOR=true` 才编译编辑器，默认关闭；关闭时产物不包含编辑器、完整配置模板或编辑器 mock 代码。
- 开启编译后，只有 URL 查询参数 `configeditor=on` 才进入编辑模式；其余访问为正常生产页面。编辑状态在首页 / 详情导航时保留，退出时移除该参数并恢复真实数据。
- 编辑模式只使用 mock，不查询真实来源；默认从不含部署信息的完整示例开始，可导入已有 JSON。浏览器不获取服务端配置、环境变量或密钥。
- 保留现有展示组件；配置草稿仅在当前页面内存中，有效修改实时预览，不显示常驻“已同步”。只有错误需要提示。
- 编辑器支持简中 / 英文，并跟随现有语言和外观偏好。

## 交互

- 右下角编辑器，表单和 JSON 编辑同一份草稿；支持直接粘贴、复制、文件导入与导出。
- 有效改动立即同步 mock 页面，没有额外的“应用”步骤；错误草稿保留输入和最后一次有效预览，暂停导出。
- 顶部深鸢尾横幅标明编辑模式；底部琥珀横幅标明本地预览和部署提示，均固定显示，适配深色。收起编辑器后仍保留。
- 鼠标离开且输入焦点离开约 850ms 后贴边，悬停、点击或键盘聚焦恢复。保留完整窗口尺寸，整体移到屏外，仅露出完整侧边，不缩成小标签。移动约 560ms；可固定展开，Escape 或收起按钮可主动贴边。
- 表单和 JSON 共用固定高度外框（桌面 700px，窄屏 660px，受可视高度限制），内部滚动；两种卡片的操作栏也等高。切换模式、分类或错误状态不会挤动底部按钮。
- 粘贴、导入、复制、格式化只放在 JSON 卡片内；底部统一保留“导出配置 JSON”。
- 模式切换交叉淡入、轻移约 420ms，分类先退场 140ms 再进场 360ms；预览页面、菜单、提示及进入 / 退出编辑模式也有过渡。连续切换会中断旧动画；遵循减少动态效果偏好。
- 列表可切换分组、搜索、打开监控详情；文字可编辑简中和英文，页面可切换预览语言和明暗外观。

## 字段

| 位置 | 内容 |
| --- | --- |
| 网站 | `name`、`logo`、导航 `label` / `href` / `newTab`、`footer`、`refreshIntervalSeconds`、`pinAbnormal` |
| 分组与来源 | 大分组 `id` / `name` / `logo`；来源类型、`apiKeyEnv`，以及 Peekaping 的 `baseUrl` |
| 子分组 | 独立的 `id` / `name` / `logo`；Peekaping 的 `slug` 或 UptimeRobot 的 `monitorIds`（含 `*`），可选 `order` |
| 监控显示 | 以监控 ID 为键的 `name` / `logo` / `description` 覆盖 |
| 缓存 | 可选 `cache.kvBinding` |

导航、大分组、子分组支持增删与上下移动。“全部”自动合并，不另配；覆盖显示不扩大公开范围。来源切换会重置子分组选择规则，原型会提示。

## 边界

原型内嵌了当前 `config/schema.ts` 的校验快照和 Zod，仅用于离线设计验证；正式实现应直接复用配置校验，不维护第二份规则。原型含 Zod 的 MIT 许可声明。

预览不查询上游。Peekaping 的模拟分组按示例顺序分配监控，不能用于验证真实状态页成员；本地 Logo 用字母标记代替。详情页图表用于展示布局，不代表真实历史。

配置只在页面内存中，刷新后恢复示例。导出为 `site.json`，不写仓库、不上传、不保存密钥；`apiKeyEnv` 仅填写 EO 环境变量名。
