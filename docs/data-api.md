# 数据与接口

全部接口公开只读，不需要浏览器传密钥。

```text
GET /api/v1/groups/:groupId
GET /api/v1/groups/:groupId/monitors/:monitorId?range=24h
```

完整响应结构见 [contracts.ts](../src/shared/contracts.ts)。时间使用 UTC ISO 8601，页面按访客时区显示；`null` 表示缺失，`0` 是真实零值。错误响应为 `{"error":{"code":"unavailable","retryAt":null}}`，只使用公共错误码，不透传上游响应或配置。

| 错误码 | HTTP | 含义 |
| --- | --- | --- |
| `not-found` | 404 | 不存在、未公开或不支持的路由 / 方法 |
| `unavailable` | 502 | 来源或服务端配置不可用 |
| `rate-limited` | 429 | 来源限流，可带 `retryAt` |
| `invalid-response` | 502 | 无效参数或响应不满足契约 |

只支持 `24h`。不同来源能力通过 `capabilities` 和 `supportedRanges` 表达，不用 24 小时数据冒充更长窗口。

## 来源口径

| 内容 | Peekaping | UptimeRobot |
| --- | --- | --- |
| 公开范围 | 配置状态页当前列出的监控 | 配置中的监控 ID |
| 首页延迟 | 最近心跳的延迟 | 最近 30 分钟聚合采样均值 |
| 详情响应 | 状态页最近心跳 | 按单个监控取原始响应采样 |
| 可用率 | 来源计算的 24 小时统计 | 来源返回的 1 天统计 |
| 历史 | 状态页最近 100 条心跳，不保证全天 | 实际响应采样与故障日志，受套餐限制 |
| 证书 | 未接入 | 未接入 |

无采样不能解释为正常；响应采样只代表观测点，不延长成整个正常区间。故障日志优先于响应点，历史缺口保留。平均响应注明实际采样范围，不跨来源平均可用率。

## 公开范围

服务端按配置选中监控，只返回展示字段。浏览器不能指定上游地址、凭证或任意查询路径。Peekaping 详情返回前确认状态页名单；名单刷新失败时拒绝详情，不借旧详情缓存扩大公开集合。

名单允许在 30 秒新鲜缓存内使用。配置变更参与版本隔离；新部署不会复用旧配置快照。动态名单撤销不承诺跨节点瞬时生效。

## 缓存与失败

- 函数节点缓存新鲜期 30 秒；仅成功快照保存到生成后 5 分钟。失败有旧结果时标旧返回，首次失败明确不可用。
- KV 是可选的短期成功快照副本；未配置、损坏、超时或故障均可降级。存储读写不会无限阻塞来源请求。
- 同一函数实例内合并在途请求，按配置版本、路由和来源凭证隔离；跨节点不做全局锁，仍受上游额度限制。
- 单个子组失败不抹掉成功子组的实时状态；整体不再报告“全部正常”。整次刷新失败保留原更新时间并标旧。
- 错误、部分成功和旧快照都传递来源限流截止时间，自动刷新遵守退避。手动刷新成功也不提前取消仍有效的退避。
- API 对浏览器 / CDN 返回 `no-store`，缓存由函数管理。浏览器关闭自动刷新后，快照超过 5 分钟也会标旧；不会因此额外请求上游。

KV 信封校验完整版本、路由和截止时间，键用 SHA-256 控制长度。不同配置版本复用槽位但不能串用内容。EdgeOne 无原生 TTL，过期值不再读取，已删除路由的键可手动清理。缓存不保存长期历史。
