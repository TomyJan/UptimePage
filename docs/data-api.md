# 数据与接口

## 来源能力

| 内容         | Peekaping                   | UptimeRobot                            |
| ------------ | --------------------------- | -------------------------------------- |
| 公开范围     | 配置状态页当前列出的监控    | 配置 ID，或 `*` 选择密钥可读的全部监控 |
| 首页响应时间 | 最近心跳延迟                | 最近 30 分钟聚合采样均值               |
| 详情曲线     | 状态页最近心跳              | 单个监控的原始响应采样                 |
| 可用率       | 上游 24 小时统计            | 上游 1 天统计                          |
| 历史         | 最近 100 条心跳，不保证全天 | 响应采样与故障日志，受套餐限制         |
| 检查周期     | 详情按需读取鉴权接口        | 上游监控配置                           |
| 证书         | 未接入                      | 未接入                                 |

目前只支持 `24h`。缺失值为 `null`，页面显示 `—`；`0` 表示真实零值。很短的检查记录以可见标记放在实际时间位置；标记宽度只方便操作，不代表持续在线。单个响应点不扩展成连续正常历史，曲线保留缺口，故障日志优先于响应点。不平均不同来源的可用率。

## 读取与缓存

- 首页只获取当前大分组，详情按需读取；同一函数实例合并重复的在途请求，跨节点不做全局锁，仍受上游额度限制。
- 节点缓存新鲜期 30 秒，成功快照最多保留到生成后 5 分钟。更新失败可返回带诊断的旧结果；浏览器保留已有快照和更新时间，首次失败显示具体错误。API 对浏览器 / CDN 返回 `no-store`，由函数管理缓存。
- 刷新、自动更新和重试均提供结果 Toast；失败显示脱敏原因及可用的 HTTP 状态，不重复添加过期提示，也不把最近一次监控状态改成“更新延迟”。
- 首次部分失败可显示已取得的监控；已有完整快照时保留它及其更新时间，直到整组成功。限流退避随成功、部分成功或旧快照传给前端，手动刷新不提前解除退避。
- Peekaping 详情先确认公开名单，再按需读取该监控的检查周期；只提取周期，不透传私有配置。周期读取失败保留公开检查数据并附带诊断及限流退避。名单刷新失败会拒绝详情。名单可在 30 秒新鲜缓存内复用，动态撤销不保证跨节点瞬时生效。配置版本变化会隔离旧快照。
- 可选 KV 保存短期成功快照，不保存长期历史；损坏、超时和故障均可降级。KV 不依赖原生 TTL，读取时校验版本和期限；已删除路由的遗留键可手动清理。

## HTTP 接口

接口公开只读，不需要浏览器传密钥；服务端只返回公开展示字段，不透传上游配置或错误。浏览器不能指定上游地址或凭证。

```text
GET /api/v1/groups/:groupId
GET /api/v1/groups/:groupId/monitors/:monitorId?range=24h
```

响应结构见 [contracts.ts](../src/shared/contracts.ts)。时间使用 UTC ISO 8601，页面按访客所选时区显示。错误格式：

```json
{
  "error": {
    "code": "unavailable",
    "retryAt": null,
    "diagnostic": { "reason": "upstream-http", "status": 403, "stage": "source" }
  }
}
```

| 错误码             | HTTP | 含义                                |
| ------------------ | ---- | ----------------------------------- |
| `not-found`        | 404  | 未公开、不存在或不支持的路由 / 方法 |
| `unavailable`      | 502  | 来源或服务端配置不可用              |
| `rate-limited`     | 429  | 来源限流，`retryAt` 可给出重试时间  |
| `invalid-response` | 502  | 参数无效或响应不满足契约            |

`diagnostic` 可选，仅包含固定原因、HTTP 状态和处理阶段，不包含上游正文、地址、密钥或异常堆栈。原因包括缺少凭证、来源拒绝、超时、网络故障、格式错误及内部异常。首次加载显示原因，刷新失败通过 Toast 展示。平台在函数外强制中止或启动失败无法被函数捕获；浏览器对非 JSON 的 HTTP 545 显示边缘函数执行失败。
