# 数据与接口

## 来源能力

| 内容               | Peekaping                                            | UptimeRobot                            |
| ------------------ | ---------------------------------------------------- | -------------------------------------- |
| 公开范围           | 配置状态页列出的监控 ID                              | 配置 ID，或 `*` 选择密钥可读的全部监控 |
| 名称、状态、周期   | 鉴权监控批量接口                                     | 上游监控配置                           |
| 首页响应时间       | 鉴权接口的最近心跳延迟                               | 最近 30 分钟聚合采样均值               |
| 详情曲线、检查历史 | 鉴权统计接口，查询完整 24 小时；按分钟或实际周期聚合 | 原始响应采样与故障日志，受套餐限制     |
| 可用率             | 鉴权接口的 24 小时统计                               | 上游 1 天统计                          |
| 近期事件           | 鉴权心跳接口，分页读取状态转换                       | 故障日志                               |
| 证书               | 未接入                                               | 未接入                                 |

目前只支持 `24h`。状态页接口**只用于分组成员 ID**，不采用其中的名称、状态、可用率或历史。实际数据全部使用服务端 API Key 查询，并只返回公开字段；密钥、目标地址和私有配置不会返回浏览器。

检查历史以 48 个时间块汇总该时段的检查结果；异常优先，混合结果显示部分异常，无记录时段留空。时间块不表示持续在线。缺失值显示 `—`，真实零值显示 `0`；曲线保留缺口，故障日志优先于响应点。不平均不同来源的可用率。

## 读取与缓存

- Peekaping 成员名单按子组独立缓存 **10 分钟**，优先 KV，未绑定或不可用时回退节点缓存；只保存 ID。到期必须重新获取，失败的子组不沿用过期名单，也不能授权详情。撤销最迟在名单缓存到期后生效，不保证跨节点瞬时同步。
- 状态和详情缓存新鲜期 **30 秒**。可选 KV 和节点缓存保留成功数据最多 5 分钟，读取时校验期限、配置版本和名单版本；旧名单对应的详情不能绕过新名单。配置变化会隔离旧缓存。
- 首页先读取当前大分组的鉴权监控概要，再以最多 4 个并发请求补齐每个监控的 24 小时数据。每个监控独立运行、缓存，避免把所有历史请求塞进一次边缘函数。详情页复用这些缓存；不读取其他大分组。
- 同一函数实例合并重复的在途请求；跨节点不做全局锁，仍受上游额度限制。缓存损坏、超时、未绑定或故障均可降级，不依赖 KV 原生 TTL。
- 刷新、自动更新和重试均提供结果 Toast，失败显示脱敏原因及可用的 HTTP 状态。已有完整快照时保留它及其更新时间，直到整组成功；确认撤销的监控和详情缓存会立即移除。
- 首次部分失败可显示已取得的数据。限流退避随错误传给前端，手动刷新不提前解除退避。API 对浏览器 / CDN 返回 `no-store`，由函数管理缓存。

## HTTP 接口

接口公开只读，不需要浏览器传密钥；服务端只返回公开展示字段，不透传上游配置或错误。浏览器不能指定上游地址或凭证。

```text
GET /api/v1/groups/:groupId
GET /api/v1/groups/:groupId/monitors/:monitorId?range=24h
```

响应结构见 [contracts.ts](../src/shared/contracts.ts)。时间使用 UTC ISO 8601，页面按访客所选时区显示。错误格式：

```json
{
  "error": {
    "code": "unavailable",
    "retryAt": null,
    "diagnostic": { "reason": "upstream-http", "status": 403, "stage": "source" }
  }
}
```

| 错误码             | HTTP | 含义                                |
| ------------------ | ---- | ----------------------------------- |
| `not-found`        | 404  | 未公开、不存在或不支持的路由 / 方法 |
| `unavailable`      | 502  | 来源或服务端配置不可用              |
| `rate-limited`     | 429  | 来源限流，`retryAt` 可给出重试时间  |
| `invalid-response` | 502  | 参数无效或响应不满足契约            |

`diagnostic` 可选，仅包含固定原因、HTTP 状态和处理阶段，不包含上游正文、地址、密钥或异常堆栈。原因包括缺少凭证、来源拒绝、超时、网络故障、格式错误及内部异常。首次加载显示原因，刷新失败通过 Toast 展示。平台在函数外强制中止或启动失败无法被函数捕获；浏览器对非 JSON 的 HTTP 545 显示边缘函数执行失败。
