# 配置编辑器实现计划

> 使用 executing-plans 在当前会话连续执行，完成后进行独立审查。

**目标：** 实现默认不编译、通过 `configeditor=on` 开启的浮动配置编辑器。

**架构：** Vite 在构建时裁掉默认关闭的动态入口。开启编辑时注入独立的公开配置、mock 客户端和 QueryClient，复用正式页面；退出时卸载并恢复生产数据。表单和 JSON 共用内存草稿及现有配置校验。

**技术栈：** 现有 React、React Query、React Router、Zod、Radix、CSS tokens；不引入新依赖。

**规格：** [已确认设计](../../../design/config-editor.md)。

## 全局约束

- 继续使用 master，不创建分支、不修改 legacy；原子提交并保留 GPG 签名。
- `UPTIMEPAGE_CONFIG_EDITOR=true` 是唯一启用值；URL 需精确包含 `configeditor=on`。
- 默认构建不得包含编辑器、示例完整配置或其 mock 代码；启用构建也不得包含实际服务端配置。
- 复用现有配色、布局组件、动画和简中 / 英文偏好；删除常驻“已同步”。
- 编辑器仅导入 / 导出，不上传、读密钥或自动保存。

## 审查重点

1. 未启用或未带参数时正常访问生产 API，编辑器代码不加载。
2. 预览首页、详情和刷新只访问独立 mock；退出后不复用预览缓存。
3. 无效、未知字段或结构错误的 JSON 保留原文和最后有效预览，禁止导出。
4. 分组空选择、重复监控、通配符及含点号的上游 ID 不破坏预览或表单。
5. 首页 / 详情导航保留编辑参数；贴边、键盘、触屏、减少动态效果和固定高度均可用。
