# UptimePage 上线准备收尾

沿用已确认的页面和数据架构，完成可在本地独立推进的工作。实际发布另行执行。

## 任务

1. [x] 补齐浏览器快照过期：即使仅手动刷新、返回旧页面或标签页长期休眠，超过 5 分钟的快照也不再表示当前正常。历史数值保留，新快照恢复实时状态，不额外发请求。
2. [x] 补齐禁用范围说明和图表时区，沿用现有自定义提示及中英文。
3. [x] 增加部署验收命令：检查真实 HTTP 响应、配置版本、公开范围、错误路由、深层页面及静态资源。使用真实函数入口的本地集成测试验证缓存、KV 降级与验收器自身；本地结果不冒充 EdgeOne 实测。
4. [x] 整理 README、配置与 EdgeOne 部署指南，提供无密钥示例，修正历史计划里的过时命令。文档只说明怎么用、怎么验收、限制在哪里。
5. [x] 运行完整检查、独立审查并修复有效发现，原子化签名提交。

## 实施决定

- 浏览器显示新鲜度上限为快照生成后 5 分钟，与服务端旧快照保留上限一致。正常轮询仍按用户选择执行；失效计时不承担刷新调度。
- 不扩展来源声明之外的历史能力；当前仅支持 24 小时，缺失证书和更长历史继续明确标缺失。
- 本轮不新增管理页、编辑器、来源、监控检查或长期存储。
- 尚无真实配置、来源密钥和 EdgeOne 预览地址时，提供可执行的验收工具并保留平台待验项，不创建虚假验收结果。

## 验收

单元、浏览器、格式、类型、构建、公开产物隔离和生产依赖审计。新增行为先复现失败再实现；最终独立审查覆盖本计划开始至结束的全部修改。

本地结果：126 项单元测试、55 项浏览器测试通过；格式、类型、生产构建、公开产物隔离及生产依赖审计通过。独立审查发现的静态资源漏检、只读检查使用不存在路由两项盲点已补回归并修复。真实来源与 EdgeOne 平台验收仍待实际配置及预览地址，按[部署指南](../../deployment.md)执行。
