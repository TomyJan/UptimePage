## 线上结果

部署提交 `33c535d`，配置版本 `b1d39ec8`，检查地址为 `https://status.tomys.top`：

- 首页及构建资源正常；Peekaping 快照、详情、详情直达、公开名单、禁止写入及 `no-store` 检查通过。
- Peekaping 共 40 个监控：`default` 为 0、`moeai` 为 1、`monitor` 为 39；快照为新鲜数据，无子组错误。三个上游公开状态页的监控数量一致。
- 全站 `verify:deployment` 因 UptimeRobot 返回 `502 unavailable` 失败；实际配置仍有占位监控 ID。此次已支持实际配置的 `*` 全量选择；其他占位 ID 仍需替换或移除。确认 EO 密钥有效后重新部署验收。
- Peekaping 间歇返回 545，已多次复现，正文为 `Error return from script`；相邻请求也有返回 200。[官方说明](https://cloud.tencent.cn/document/product/1552/101095)将 545 归为边缘函数执行异常，具体根因尚未确定。EO 函数日志官方仍在规划中，不再以取得日志作为排查前提。新版返回脱敏诊断，并识别非 JSON 的 545；部署后记录时间、请求标识（响应头若有）、发生频率及可用的平台指标。本地处理正常不能排除平台强制中止。
