# 验证状态

截至 2026-10-21，代码已完成本地验证与独立审查；真实来源及 EdgeOne 平台尚未验收。当前默认配置仍含示例地址和监控 ID。

## 本地结果

- 最新单元 / 集成回归 133 项通过，最近一次浏览器回归 55 项通过；格式、类型、构建及公开产物隔离检查通过，生产依赖审计未发现已知漏洞。
- 覆盖来源字段、分页、公开名单、配置回退、缓存期限、可选 KV 故障、限流退避、并发请求合并与部分失败。
- 浏览器覆盖手机、桌面、中英文、深浅色、键盘 / 触屏、动效、旧快照及错误恢复。真实函数入口测试使用受控上游，不代表平台实测。

执行方法见[开发与测试](development.md)，HTTP 验收命令见[部署指南](deployment.md#3-检查部署)。修复过程与历史测试记录保存在 Git 历史中。

## 上线前检查

- [ ] 提交真实 `config/site.json`，设置来源密钥；核对实际监控数量、状态、响应与历史范围。
- [ ] EO 预览通过 `pnpm run verify:deployment`，确认函数路由、运行时变量、静态资源和详情直达 / 刷新正常；空组详情 `SKIP` 不能当作通过。
- [ ] 在预览环境检查手机、中英文、深浅色，以及手动刷新和自动更新。
- [ ] 用测试来源模拟不可达和限流，确认首次失败、旧数据标旧、退避及恢复；关闭自动刷新，5 分钟后应标旧。
- [ ] 检查实际规模和并发下的函数 CPU、错误率及上游额度；实例内请求合并不等于全站合并。
- [ ] 若启用 KV，验证已绑定、未绑定、存储故障和节点缓存清除后的恢复，不破坏生产命名空间。
- [ ] 对照 UptimeRobot 实测窗口前开始、仍持续或跨入 24 小时窗口的故障。官方文档未明确日志时间过滤的相交规则。

数据能力和统计口径见[数据与接口](data-api.md)。通过本地测试不等于完成以上检查。
