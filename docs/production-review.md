## 平台演练

在独立预览部署 `e6dafa4` 中执行，使用合成配置和测试键；不修改生产配置、凭据或 KV。断网、429 和 KV 异常在预览函数内注入，不代表真实来源发生过这些故障。

| 场景               | 实测结果                                         |
| ------------------ | ------------------------------------------------ |
| 未绑定 KV          | 实时取数成功，随后命中同一实例缓存，不再请求来源 |
| 来源断网或 429     | 返回旧快照及脱敏错误，保留原更新时间             |
| 来源恢复           | 返回新快照，更新时间前进                         |
| 清空测试缓存后断网 | 返回脱敏的 502；恢复来源后重新取数成功           |
| 注入 KV 读写异常   | 继续成功取数                                     |

该 `edgeone.cool` 预览环境存在 Cache API 对象，但写入返回 `forbidden cdn cache`。同一次边缘执行对 `max-age`、`s-maxage` 及两者组合均得到相同结果；不能把缓存桥 HTTP 200 当成节点缓存命中。演练确认实例缓存能够回退，**没有证明预览节点缓存可用**，也不能据此推断自定义域名的能力。未绑定 KV 时，冷实例或换节点遇到来源故障可能没有旧快照；需要跨实例复用时启用 KV。

临时平台探针与故障注入未合入 master。
